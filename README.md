SREQUEST:

SRequest is a single-header C networking library for Windows
Build on top of Winsock library.

Installation:
- Download SRequest library
- Include it in your C files like this:
#include "SRequest.h"

Requirements:

- Windows;
- A C compiler (MinGW, Clang, etc)

Compiler:

Ex (GCC): gcc [namefile].c -o [output].exe -lws2_32
